# Portfolio — Eutch Présence BITSINDOU

Portfolio personnel orienté actuariat, data et gestion des risques.

## Structure

- `index.html` : page principale du portfolio
- `assets/profil.jpeg` : photo de profil
- `.nojekyll` : publication directe du site statique avec GitHub Pages

## Publication GitHub Pages

Dans le dépôt GitHub :
1. Ouvrir `Settings`
2. Aller dans `Pages`
3. Sous `Build and deployment`, sélectionner `Deploy from a branch`
4. Choisir la branche `main`
5. Choisir `/(root)`
6. Cliquer sur `Save`

Le site sera ensuite accessible via GitHub Pages.
